# CityLens 架构决策记录（ADR）

本文件记录会影响产品边界、安全性、接口或后续维护成本的决定。新增记录不修改旧记录的结论；若决定被替代，应标记为“已替代”并链接到新记录。

## ADR-001：CityLens 是环境理解辅助，不是导航系统

| 项目 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-09-22 |
| 背景 | 视觉模型对单帧理解存在不确定性，MVP 时间和设备条件不足以验证道路导航安全性。 |
| 决定 | 只报告清晰可见的环境事实，不提供转向、过马路许可、自动驾驶式导航或“安全通过”结论。 |
| 后果 | 演示和 API 文案必须保留辅助工具边界；安全性比“听起来聪明”的描述优先。 |

## ADR-002：MVP 不生成精确距离

| 项目 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-09-22 |
| 背景 | Link 2、X4 Air 的普通 RGB/全景画面并不天然提供经过标定的深度。 |
| 决定 | 事件模型不包含米级距离；只允许“左前方、前方、右前方”等相对方向，以及可选的保守远近表述。 |
| 后果 | 任何增加距离字段的提案都必须说明传感器、标定、误差测试和安全审查。 |

## ADR-002a：服务端 5 米粗过滤（不向用户展示距离数字）

| 项目 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-09-22 |
| 背景 | 用户要求“只识别 5 米内的环境”；模型契约仍禁止返回距离（ADR-002）。参考开源助盲项目的视尺寸估算思路，只能用框的表观大小做粗过滤。 |
| 决定 | 后端在 HTTP 与实时两条通道的 summarize 之前，按针孔模型用各类别标称高度反推粗略距离，超过 `CITYLENS_MAX_DISTANCE_M`（默认 5，≤0 关闭）的事件静默丢弃；无框、畸形框与斑马线（地面目标）因无法判断而保留。估算值只出现在服务端日志，绝不进入事件、播报或 UI 文案。 |
| 后果 | 这是粗估而非测量：真实尺寸分散、框误差、Link 2 变焦和云台俯仰都会带来数倍误差，只能当噪声过滤器，不能当安全依据。后续若需要可靠距离，须按 ADR-002 后果条款走标定/误差测试/安全审查（例如深度模型或双目标定）。 |

## ADR-003：实时输入帧默认不持久化
| 项目 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-09-22 |
| 背景 | 城市画面可能包含人脸、车牌、地点和其他无关敏感信息；MVP 不需要历史回放。 |
| 决定 | 图片仅在浏览器/后端内存中完成当次分析；不写数据库、不写 OSS、不写应用日志。OSS 仅用于授权 Demo 素材和受限的可过期对象。 |
| 后果 | 评测和录像需要单独授权、去标识和保留期限；任何持久化功能必须先更新数据治理文档。 |

## ADR-004：模型输出必须经过严格 schema 与服务端规则

| 项目 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-09-22 |
| 背景 | 自由文本模型输出可能携带幻觉、无关建议或不安全的导航表述。 |
| 决定 | 只接受受控类别、标签、方向和长度受限的文字；后端执行模式过滤、排序、去重和一条播报选择。 |
| 后果 | 增加识别类别是接口变更，必须同时更新模型、规则、前端类型、API 文档和测试。 |

## ADR-005：先用百炼 API，不在 MVP 部署本地模型或训练模型

| 项目 | 内容 |
|---|---|
| 状态 | 已采纳 |
| 日期 | 2026-09-22 |
| 背景 | 项目时间短，团队已有百炼调用服务与 ECS/OSS；本地模型会引入 GPU、模型下载、运维和性能调优风险。 |
| 决定 | 百炼视觉模型是主推理路径；ECS 仅承担网页、后端、规则和受控调用。 |
| 后果 | 不需要为 MVP 申请 GPU；模型名称、配额、延迟和成本必须在真实调用中验证。 |

## ADR-006：云端部署采用私有 OSS 与最小 RAM 权限

| 项目 | 内容 |
|---|---|
| 状态 | 目标架构，待实现与验收 |
| 日期 | 2026-09-22 |
| 背景 | 演示素材和 API 密钥若被公开会引入隐私、费用和滥用风险。 |
| 决定 | OSS Bucket 默认私有；ECS 运行时优先使用 RAM 角色访问限定前缀；浏览器不持有云端长期凭据。 |
| 后果 | ECS 公网部署前需要完成 TLS、CORS/可信主机配置、生命周期策略和权限测试，详见 `运维手册.md`。 |
