# CityLens 云端部署与运行手册

| 字段 | 内容 |
|---|---|
| 版本 | v0.1 |
| 更新日期 | 2026-09-22 |
| 适用环境 | 本地开发、ECS 演示环境、OSS 演示素材、阿里云百炼 API |

## 1. 当前状态与上线边界

当前仓库的默认运行方式是本机 `localhost:8000`，并且后端可信主机、允许来源均限制为本地地址。它适合开发与本机演示，**不能直接视为已完成公网部署**。

在 ECS 上部署前，必须先完成 [ARCHITECTURE.md](ARCHITECTURE.md) 中“目标 ECS 部署前的必做实现项”，尤其是可信主机/CORS 的环境化配置、HTTPS、Nginx 反向代理、RAM 角色和上线测试。部署配置应经代码评审和测试，不要通过临时放开所有来源或安全组端口来“快速解决”。

## 2. 环境与账号职责

| 环境 | 用途 | 模型供应商 | 素材 | 最低要求 |
|---|---|---|---|---|
| `local-sample` | UI、流程与自动化测试 | 固定样例 | 本地合成/授权素材 | 不使用真实密钥 |
| `local-live` | 授权图片和设备联调 | 百炼真实模型 | 本地授权素材 | `.env` 仅存本机，测试后核对日志 |
| `ecs-demo` | HTTPS 演示与受控联调 | 百炼真实模型 | 私有 OSS / 本地输入 | 私有网络边界、RAM 最小权限、备用视频 |

建议的权限分离：

| 身份 | 最小职责 |
|---|---|
| 部署 RAM 用户 | 仅管理指定 ECS、部署所需的镜像/文件和指定 OSS Bucket |
| ECS 运行时 RAM 角色 | 仅访问 CityLens 指定 Bucket 的所需前缀；不授予账号管理权限 |
| 百炼 API Key 持有者 | 仅创建/轮换项目 API Key；密钥不进入前端或仓库 |
| 演示人员 | 仅打开应用和授权浏览器摄像头；不需要云账号权限 |

不要使用主账号日常部署；不要把 `AccessKey`、`Secret`、百炼 API Key 或签名 URL 写进 README、PPT、录屏、浏览器控制台或 Git 提交。

## 3. 配置与密钥

现有后端读取以下环境变量：

```dotenv
CITYLENS_PROVIDER=live
DASHSCOPE_API_KEY=
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
DASHSCOPE_MODEL=qwen3-vl-plus
CITYLENS_SAMPLE_SCENE=bicycle
```

规则：

1. 正式环境必须使用 `CITYLENS_PROVIDER=live`；样例模式只能用于明确标识的演示或测试。
2. `DASHSCOPE_MODEL` 以当前百炼控制台实际授权的视觉模型为准；改模型前先用一张授权图验证 JSON 兼容性、延迟和费用。
3. `.env` 已被忽略，只能放在本机或 ECS 运行环境；仓库只保留 `.env.example`。
4. 生产部署应使用密钥管理能力或受限环境变量注入。若 API Key 泄露，立即吊销/轮换并检查部署日志与提交历史。

未来接入 OSS 后，可新增 `OSS_BUCKET`、`OSS_REGION`、`OSS_PREFIX` 等**非密钥**配置；优先由 ECS RAM 角色获取临时授权，避免在应用中保存 OSS 长期 AccessKey。

## 4. ECS 网络与进程要求

```text
Internet
   │ 仅 443（必要时 80 跳转至 443）
   ▼
Nginx on ECS
   ├─ 提供前端静态文件
   └─ /api 反向代理到本机 FastAPI
                       │
                       └─ 百炼 HTTPS API / 私有 OSS
```

部署检查：

- [ ] ECS 安全组对公网仅开放 `443`，如需证书签发可短期开放或重定向 `80`；SSH `22` 仅限维护人员固定 IP。
- [ ] FastAPI 监听本机回环地址或私有网络，不直接暴露 `8000`。
- [ ] 域名已配置 HTTPS。移动端网页获取摄像头通常需要安全上下文，HTTP 页面不能作为正式演示路径。
- [ ] Nginx 设置合理的上传大小、请求超时和安全响应头；上传大小应与 API 的 2 MiB 限制一致。
- [ ] 已将正式域名加入受控的可信主机/CORS 配置，并保留 `localhost` 仅供开发；未知来源请求必须失败。
- [ ] `/api/health` 可用，但不得将其当作模型权限已验证的证据；必须另做授权图片真实请求。

## 5. OSS 运行规范

1. 创建私有 Bucket，地域尽量与 ECS 一致以降低延迟和流量成本。
2. 运行时不将实时每帧上传 OSS；默认只保存授权的演示视频、测试图片和已审查产物。
3. Bucket CORS 仅允许正式演示域名和必要的本地开发来源；禁止 `*` 配合凭据。
4. 为 `temp/` 设置生命周期自动删除；对删除规则做一次可复查的测试。
5. 对展示资源使用短期、最小范围访问方式；不要公开 Bucket 列表、公开写入或在客户端放管理密钥。
6. 演示完成后由素材负责人复查和清理无继续使用理由的原视频、测试帧和临时对象。

对象键和保留规则见 [DATA_MODEL.md](DATA_MODEL.md)。

## 6. 发布、回滚与演示前检查

### 6.1 建议发布流程

```text
功能分支
   ↓
代码审查：PRD / API / 数据模型 / 测试是否同步
   ↓
本地自动化测试 + 前端构建
   ↓
部署到受控 ECS 演示环境
   ↓
HTTPS、真实模型、摄像头、语音、备用视频彩排
   ↓
记录版本号、提交号、模型名、日期和已知限制
```

### 6.2 发布前最小检查

- [ ] 运行 `.\scripts\test.ps1 -Browser` 成功；
- [ ] `CITYLENS_PROVIDER=live` 且 `/api/health` 显示已配置；
- [ ] 至少一张授权图片的真实模型调用成功；
- [ ] 手机/演示电脑在 HTTPS 域名下可以请求摄像头；
- [ ] 中文语音、静音、暂停、重播、停止均人工验证；
- [ ] 网络断开、模型限流和超时不会播放旧提示；
- [ ] 预录 MP4 已能本地播放，且备用模式标识清楚；
- [ ] 版本与配置负责人已记录在 `PROGRESS.md`，不记录密钥。

### 6.3 回滚与现场故障

| 症状 | 立即动作 | 后续记录 |
|---|---|---|
| 模型认证/限流/网络连续失败 | 暂停自动识别，切换为预录备用流程 | 记录错误码、时间、版本；不记录图片或 Key |
| 摄像头权限或设备失败 | 释放输入，提示重新连接；改用授权视频 | 记录设备、浏览器和权限状态 |
| 新版本主流程失败 | 回滚到上一个已通过演练的提交/构建产物 | 记录版本差异、复现步骤和负责人 |
| 疑似密钥泄露 | 立即轮换/吊销密钥、停止暴露环境 | 审查日志、提交和访问范围；不要在群聊粘贴密钥 |

## 7. 可观测性与成本记录

建议只记录以下低敏感运行指标：

```text
时间、环境、版本、模型名、状态、错误码、事件数量、服务端 latency_ms
```

不要记录：原始帧、完整视频、Base64、完整 OCR 文本、上游模型原始回复、API Key、RAM 凭据、用户身份或精确位置。

每轮真实模型测试记录总请求数、成功数、失败分类、P50/P90 时延以及实际账单/Token 数据。价格、配额和模型可用性均以当前阿里云控制台为准，不在文档中填写未经核实的数字。
