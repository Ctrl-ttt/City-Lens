## 真实模型评测

障碍物、设施、文字、空/模糊场景各 10 张，各类 5 张调试、5 张冻结。人工预期在跑模型之前写入，不在看到结果后修改。原图放被忽略的 local-data/，只用有授权素材。

| 图片匿名 ID | 调试/冻结 | 类别 | 人工预期 | 实际类型/方向/文字 | 遗漏/无依据内容 | 耗时 ms | 判定 |
|---|---|---|---|---|---|---|---|
| 待录入 | | | | | | | |

内部目标：冻结的 15 张任务图至少 12 张提取核心信息，5 张空/模糊图不编造障碍或通行结论；看牌关键数字/路名逐项核对。此为小样本原型目标，不是已经达到的识别准确率。

至少 30 次真实请求记录端到端耗时（前端指标包括抽帧与网络），P90 采用排序后第 ceil(0.9×N) 项；失败另报，不删除慢请求。目标 P90≤5 秒，未达到就使用“只用按键识别”并如实说明。
