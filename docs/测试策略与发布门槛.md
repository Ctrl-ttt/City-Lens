# CityLens 测试设计与发布质量门槛

| 字段 | 内容 |
|---|---|
| 版本 | v0.1 |
| 更新日期 | 2026-09-22 |
| 原则 | 样例模式测试证明软件流程；真实模型、设备与用户测试才证明现场能力 |

## 1. 测试目标

测试要回答五个不同的问题，不能互相替代：

1. **代码正确吗？**——单元与接口契约测试。
2. **页面完整闭环吗？**——浏览器端到端测试。
3. **模型在授权素材上可靠吗？**——冻结评测集与人工复核。
4. **设备、网络和语音在现场可用吗？**——人工设备与演练测试。
5. **产品边界安全吗？**——隐私、错误处理、可访问性与不作导航承诺的检查。

## 2. 测试分层

| 层级 | 覆盖对象 | 主要方式 | 通过标准 |
|---|---|---|---|
| 单元测试 | JSON 解析、标签白名单、排序、去重、会话隔离、语音队列 | Pytest、Vitest | 规则变更必须新增或更新相应测试 |
| API 契约测试 | `/api/health`、`/api/analyze`、请求限制、错误壳、无密钥泄露 | FastAPI `TestClient` + 模拟上游 | 响应符合 `接口契约.md`，无效输入和上游异常受控 |
| 浏览器 E2E | 摄像头模拟、MP4 输入、模式切换、暂停、过期结果、窄屏布局 | Playwright + 本地样例服务 | 完整用户流程不报页面错误，不显示旧结果 |
| 真实模型评测 | 授权冻结图片、模型名、识别结果和时延 | 人工标注 + 百炼真实调用 | 结果记录可复查，不将调试结果混入冻结集 |
| 人工设备测试 | Link 2、X4 Air 素材、中文语音、手机/演示电脑、网络中断 | 检查表和录屏 | 每项有日期、设备、操作者和结果 |
| 安全与无障碍检查 | 密钥、日志、权限、焦点、键盘、屏幕阅读器、错误文本 | 人工审查 + 自动检查 | 不暴露敏感数据；核心操作可完成 |

## 3. 自动化测试设计

### 3.1 后端

后端测试至少覆盖：

- 允许的类别、标签、方向、文本长度与未知字段拒绝；
- 行走与看牌模式过滤；
- 台阶/障碍/设施排序、去重和三项上限；
- 模型返回 Markdown 围栏 JSON、无效 JSON、超长输出和未定义字段；
- 模型认证、限流、不可用、超时、网络错误和内部错误的受控响应；
- JPEG MIME、文件大小、像素限制、字段重复和元数据校验；
- 忙碌时 `429 busy`，而不是排队旧帧；
- 响应、日志和健康接口均不泄露密钥或上游错误正文。

### 3.2 前端

前端测试至少覆盖：

- 同一时间只有一帧在飞行；
- 输入、模式、暂停或视频位置变更后取消旧请求；
- 超过时效的结果不显示、不进入语音队列；
- 连续三次失败后自动暂停；
- 同一提示 8 秒内不自动重复；高优先级能够中断低优先级播报；
- 静音、停止和会话切换能清空待播内容；
- 390 px 窄屏无水平溢出，关键按钮在用户确认前不可用。

### 3.3 推荐命令

在仓库根目录运行：

```powershell
.\scripts\test.ps1
.\scripts\test.ps1 -Browser
```

测试不应调用真实付费模型、读取个人 Chrome 配置或将素材上传到外部服务。若新增测试依赖或改变命令，必须更新 `README.md` 和本文件。

## 4. 真实模型评测设计

真实模型评测流程：

```text
取得素材授权
        ↓
建立匿名 case_id 与人工预期
        ↓
将调试集与冻结集分开
        ↓
冻结提示词、模型名、规则版本
        ↓
运行真实模型并记录结果、时延、错误
        ↓
人工复核“漏报、无依据内容、错误文字、错误方向”
        ↓
记录结论；不得事后修改人工预期
```

### 4.1 最小测试集

| 类别 | 建议数量 | 例子 | 重点风险 |
|---|---:|---|---|
| 障碍物 | 10 | 单车、围挡、路障、台阶 | 漏报近处风险、重复播报、错误方向 |
| 道路设施 | 10 | 斑马线、电梯、出入口、公交站 | 把设施说成通行许可 |
| 看牌文字 | 10 | 路牌、门牌、楼层、指示牌 | 幻觉补字、数字或路名错误 |
| 空白/模糊 | 10 | 模糊、遮挡、无相关目标 | 虚构障碍、虚构文字、无依据建议 |

其中每类至少 5 张可用于调试，另 5 张冻结。MVP 的小样本内部目标与记录模板见 [验收记录](验收记录.md)，不能把该目标宣传为正式识别准确率。

### 4.2 关键指标

| 指标 | 定义 | MVP 目标 |
|---|---|---|
| 核心信息命中 | 冻结任务图中，是否提取到人工预期的关键事件/文字 | 至少 12/15 张任务图命中核心信息 |
| 无依据内容 | 空白/模糊图中捏造事件、文字或通行结论的数量 | 5 张空/模糊图为 0 条虚构安全结论 |
| OCR 核验 | 关键路名、数字、楼层逐字人工核对 | 不确定时必须报“不清晰”而非补全 |
| 端到端时延 | 从前端取帧到前端收到结果的耗时 | 至少 30 次真实请求，P90 ≤ 5 秒 |
| 失败率 | 认证、限流、网络、超时、输出无效等失败 / 总请求 | 单独列出，不通过删除慢请求掩盖 |

## 5. 现场与异常场景矩阵

| 编号 | 场景 | 预期结果 |
|---|---|---|
| M-01 | 摄像头权限被拒绝或设备被拔出 | 明确错误、释放资源、可重试，不继续播旧结果 |
| M-02 | 视频拖动、切换相机、切换看牌模式 | 旧请求取消，旧结果不显示或播报 |
| M-03 | API Key 缺失、认证失败或模型限流 | 显示受控中文错误，无样例回退，无密钥泄露 |
| M-04 | 超时或网络断开 | 当前帧作废；连续三次失败后暂停自动识别 |
| M-05 | 同一单车持续出现在多帧 | 8 秒内不重复语音 |
| M-06 | 低优先级设施提示后出现台阶 | 台阶提示优先，可中断低优先级语音 |
| M-07 | 无中文可用语音 | 页面保留文字并说明语音不可用；不假装已播报 |
| M-08 | 键盘和屏幕阅读器操作 | 确认、启动、暂停、静音、重播、停止均可达且状态可读 |
| M-09 | 连续运行 10 分钟 | 不积压请求或语音，不持续增长错误；停止后可恢复 |
| M-10 | 实时链路失败 | 切换到明确标注的预录路线备用方案 |

## 6. 发布质量门槛

任何演示或部署版本至少需要：

- [ ] 自动化测试、前端构建均通过；
- [ ] `.env`、日志、截图和提交记录中无真实密钥；
- [ ] API 与数据模型文档和实现一致；
- [ ] 真实模型权限使用一张授权图片验证成功；
- [ ] 已完成一次设备、语音、网络异常和备用视频彩排；
- [ ] 已记录当前模型、规则版本、测试日期、设备和已知限制；
- [ ] 文案未声称精确测距、自动导航、通行许可或替代专业辅助设备。

## 7. 缺陷分级与处理

| 级别 | 示例 | 处理要求 |
|---|---|---|
| P0 | 泄露密钥、把样例当真实识别、持续播放旧风险提示、输出通行许可 | 停止演示或发布，立即修复并复测 |
| P1 | 关键按钮不可用、模式混淆、模型错误未受控、现场主流程失败 | 本次发布前修复，或移除受影响能力 |
| P2 | 单个标签顺序、文案、非核心视觉问题 | 记录并安排后续版本 |
| P3 | 不影响使用的样式或文档问题 | 合并到维护任务 |
